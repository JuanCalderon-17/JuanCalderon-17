## 🚀 Projects

### FinanceManagerApp · [Live](https://finanzasbr.com)
Full-stack personal finance manager deployed to production. JWT auth, 
multi-currency support with live exchange rates, debt/installment tracking, 
savings accounts, and a Chart.js dashboard. Supports Spanish, English, 
and Portuguese.

`ASP.NET Core 9` `Angular 19` `PostgreSQL` `EF Core` `Docker` `Render` `Vercel`

---

### cdpTracker
Operational tool built for McDonald's CDP kiosk workers — replaces a manual, 
error-prone envelope logging process with a secure web app. Features 
role-based auth (Worker/Manager), kiosk-scoped data isolation, weekly 
financial summaries, and an automated midnight cleanup via a .NET Hosted Service.

`ASP.NET Core 9` `Angular 19` `PostgreSQL` `EF Core` `JWT` `Role-based Auth`

---

Java Swing desktop application for managing student records — registration, 
course enrollment, grade assignment, and record updates through a clean GUI.
